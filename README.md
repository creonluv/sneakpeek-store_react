# Sneakpeek e-commerce platform

A single-page application that implements full online store functionality. Users can browse, search, sort, and filter products, view detailed product information, and manage favorites and cart items with quantity adjustments. The app includes a responsive and cross-browser UI, promo code system, and order placement flow. It also features JWT-based authentication, a user profile with editable data, and full localization support. 
## [DEMO](https://creonluv.github.io/sneakpeek-store_react/)

## Features

- **Adaptive layout**: Guarantees a fluid and responsive experience across various devices (phones, tablets, desktops).
- **Redux Toolkit integration**: The entire application is built and managed using Redux Toolkit, providing efficient, scalable, and consistent state management.
- **JWT authentication**: Secure login and protected routes using JSON Web Tokens.
- **User profile management**: Users can view and update their profile information.
- **Internationalization (i18n)**: Full support for multiple languages.
- **Promo code system**: Apply discount codes during checkout.
- **Cart**: Cart contents are stored on the server, allowing users to retain their selected products across sessions and devices.
- **Favorites**: Favorite products are saved in the user’s profile on the server, ensuring easy access anytime the user logs in.
- **Product filtering and sorting**: Users can filter products by category, size, or price and sort them by relevance or cost.
- **Slide-out mobile menu**: Tailored for mobile users, offering an easy-to-use navigation method.
- **Cross-browser compatibility**: Consistent performance across all major browsers.
- **Interactive sliders**: Visually enhance the interface with dynamic promotional or featured product displays.
- **React Router navigation**: Facilitates smooth and seamless navigation between different pages of the application.

## Requirements

To run this project locally, you will need:

- Node.js v14 or higher
- npm or yarn

## Installation and Running

1. Clone the repository:

   ```bash
   git clone https://github.com/creonluv/sneakpeek-store_react
   cd sneakpeek-store_react
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the project:

   ```bash
   npm start
   ```

   Open your browser and go to http://localhost:3000 to view your application.
